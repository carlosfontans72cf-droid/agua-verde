🪵 Sobre la App

Diseñada para la gestión diaria de inventario en chacras turísticas, hoteles de campo, cabañas y estancias ecológicas. Divide las tareas y mercaderías por sectores funcionales de manera simple, rápida y en tiempo real.

Sin Servidor Requerido PWA Instalable

🛡️ Roles y Seguridad (Explicación)

  • Propietario / Dueño: Visualiza la consolidación de todos los sectores, lee y puede purgar el histórico completo, y autoriza administradores globales.
  • Administrador de Sector: Administra stock de su área, crea/anula accesos rápidos para su personal y realiza bajas de inventario que van al histórico.
  • Personal (Staff): Añade mercadería y ajusta el stock con botones rápidos para pantallas móviles.

🚀 ¿Cómo Deployar Gratis? (Sin Render)

  1. Copia este código HTML a tu cuenta en Vercel, Netlify o GitHub Pages para tener la app web en vivo y accesible desde cualquier celular en segundos.
  2. Crea una cuenta gratuita en Supabase.com y crea un proyecto.
  3. Ejecuta el archivo supabase_schema.sql en el editor SQL de Supabase.
  4. Pega tus credenciales haciendo clic en "Conectar Base de Datos" arriba, ¡y listo! Sincronización realtime mundial.

Conectar Base de Datos en Tiempo Real

Conecta tu propia base de datos gratuita de Supabase

💡

Para dejar de usar el Modo Demo y conectar tus dispositivos reales (Android, iPhone y PC), debes configurar tu base de datos en Supabase. Es 100% gratuito e instantáneo.

🔧 Instrucciones para activar la Base de Datos:

  1. Crea un proyecto en supabase.com.
  2. En el menú lateral ve a SQL Editor -> New Query.
  3. Copia el contenido del archivo supabase_schema.sql que creamos en tu directorio del workspace, pégalo allí y dale a Run.
  4. Ve a Project Settings (icono engranaje) -> API para obtener tus claves "Project URL" y "Anon Public Key" y pégalas aquí arriba.
