Conecta tu plan gratuito de Supabase

✨

Para habilitar la app en teléfonos reales en tu chacra, debes conectarla a una base de datos. Supabase es una opción gratuita y súper rápida que se configura en minutos.

📋 Pasos Rápidos de Inicialización:

  1. Crea un proyecto gratis en supabase.com.
  2. Entra a la sección SQL Editor -> haz clic en New Query.
  3. Copia el contenido del archivo supabase_schema.sql, pégalo allí y dale a Run.
  4. Ve a Project Settings (engranaje) -> API para obtener tus claves "Project URL" y "Anon Key" y pégalas aquí arriba.
