Sistema inalterable de auditoría e inventarios en tiempo real para estancias rurales de alto estándar. Diseñado específicamente para evitar el despilfarro, rastrear mermas y coordinar al personal sin fricción técnica.

100% Sin Costo Postgres Realtime

🔑 Reglas de Control & Seguridad

  • Nombres Reales: Todo el personal ingresa obligatoriamente con su Nombre, Apellido y Código, asegurando responsabilidad individual.
  • Longitud de Códigos: Restricción estricta de 4 a 6 caracteres para que sean memorizables e infalibles.
  • Cero Stock Negativo: El sistema bloquea de inmediato transacciones que retiren más mercadería de la existente, previniendo errores.

Base de Datos en Tiempo Real

Conecta tu plan gratuito de Supabase

✨

Para habilitar la app en teléfonos reales en tu chacra, debes conectarla a una base de datos. Supabase es una opción gratuita y súper rápida que se configura en minutos.

📋 Pasos Rápidos de Inicialización:

  1. Crea un proyecto gratis en supabase.com.
  2. Entra a la sección SQL Editor -> haz clic en New Query.
  3. Copia el contenido del archivo supabase_schema.sql, pégalo allí y dale a Run.
  4. Ve a Project Settings (engranaje) -> API para obtener tus claves "Project URL" y "Anon Key" y pégalas aquí arriba.
